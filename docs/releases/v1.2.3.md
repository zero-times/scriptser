Scriptser 1.2.3 适用于 macOS 13+，本安装包同时支持 Apple 芯片（arm64）和 Intel（x86_64）。

### 说明

- 本版本与 1.2.2 代码一致，仅用于验证应用内自动更新链路：从 1.2.2 安装的客户端应能在“管理 → 检查更新”中检测到 v1.2.3，并通过“安装并重启”完成下载、校验、替换与重启。
- 1.2.2 已修复自动更新“安装并重启”卡在“正在安装更新…”的问题：更新窗口会先收起再退出，辅助进程完成应用替换与重启；重启期间按钮保持禁用，失败路径会正确解锁界面并显示错误。

### 安装

下载 `Scriptser-1.2.3-universal.dmg`，打开后将 `Scriptser.app` 拖入“应用程序”。打开应用后点击菜单栏的终端图标，进入“管理”。现有脚本和偏好设置会保留。

此构建沿用此前版本的 ad-hoc 签名，未经过 Apple Developer ID 签名或公证。如果 macOS 阻止首次打开，请确认下载来源，并按系统提示在“系统设置 → 隐私与安全性”中选择“仍要打开”。

`SHA256SUMS.txt` 提供安装包校验值。
