Scriptser 1.3.0 适用于 macOS 13+，同时支持 Apple 芯片（arm64）和 Intel（x86_64）。

### 界面更新

- 管理窗口和菜单栏统一为简洁脚本列表：默认显示名称和一行备注，命令、目录、标签、运行历史及进程信息按需展开。
- 将运行状态整合为可点击按钮：未运行时“运行”，运行时“运行中 · 停止”，完成后显示“成功 · 运行”“失败 · 重试”或“已停止 · 运行”。文字、图标及系统语义颜色共同表达状态。
- 点击脚本名称或箭头查看/收起详情；“更多操作”和右键菜单提供详情、编辑和运行操作，管理窗口另提供输出及删除。菜单栏编辑会打开管理窗口中的编辑器。
- 新增可选多行备注，支持备注搜索、编辑保存及 JSON 导入导出；已有配置无需迁移，缺少备注时按空备注读取。
- 详情保留 PID 和“结束进程”，输出查看器保留实时日志功能；提供辅助功能操作入口与中英文文案。
- 同步应用内生成的操作 Skill，并加入可复用的通用架构打包脚本。

### 安装

下载 `Scriptser-1.3.0-universal.dmg`，打开后将 `Scriptser.app` 拖入“应用程序”。现有脚本和偏好设置会保留，也可从旧版应用内检查更新。

此构建沿用此前版本的 ad-hoc 签名，未经过 Apple Developer ID 签名或公证。如果 macOS 阻止首次打开，请确认下载来源，并按系统提示在“系统设置 → 隐私与安全性”中选择“仍要打开”。`SHA256SUMS.txt` 提供安装包校验值。
