Scriptser 1.3.1 适用于 macOS 13+，支持 Apple 芯片（arm64）和 Intel（x86_64）。

### 代码控制 Skill

- `scriptser-control` 改用纯代码与脚本操作：随 Skill 提供 Python 3 标准库客户端、JSON 接口参考和操作指引，无需电脑操作工具、界面点击或辅助功能权限。Scriptser 在已登录会话中运行、Mac 保持唤醒时，可在锁屏期间继续调用。
- 新增应用原生 Unix socket 接口，支持脚本查询、新建/编辑、运行/停止、指定 PID 强制结束、输出读取/清空、导入导出、偏好设置、Skill 生成和应用更新。命令仍由应用现有进程管理器执行，界面与代码共享状态。
- 接口仅接受同一用户的本地连接，socket 权限为 0600，带单实例锁、请求大小和读取时限约束，不开放 TCP 端口。DEV 使用独立端点和 Skill。
- 应用内生成器可直接升级旧版生成的 UI Skill，更新指引与客户端、移除旧版内置 UI 说明，保留额外文件；同步更新中英文安装说明。

### 执行与状态

- 正常停止会等待实际进程退出后更新状态；忽略终止信号的脚本继续显示运行中，避免重复启动或误删。
- 接口保存脚本时先写入磁盘再更新共享状态；失败会返回结构化错误。启动成功但时间戳保存失败时明确提示检查状态，客户端不会自动重试。
- 输出缓冲大小设置接入实际输出截断逻辑；脚本启动日志不再包含完整命令。

### 安装与使用

下载 `Scriptser-1.3.1-universal.dmg`，打开并将应用替换到“应用程序”。脚本和偏好设置保留。旧版 Skill 需要升级应用后，在“AI Skill”中重新生成；已运行新版的用户也可通过 `skill.generate` 更新技能。

```sh
python3 ~/.codex/skills/scriptser-control/scripts/scriptserctl.py status
python3 ~/.codex/skills/scriptser-control/scripts/scriptserctl.py scripts.list
```

接口要求应用运行。`launch` 会显式打开应用，可能触发用户设置的随应用启动脚本；客户端不会在连接失败时自动启动应用。退出应用后已追踪的进程仍可继续运行，输出缓冲不会跨应用重启保留。

安装包沿用此前版本的 ad-hoc 签名，未经过 Developer ID 签名或 Apple 公证。`SHA256SUMS.txt` 提供安装包校验值。
