Scriptser 1.2.4 适用于 macOS 13+，本安装包同时支持 Apple 芯片（arm64）和 Intel（x86_64）。

### 修复

- 修复 GitHub API 限流时应用内更新只剩“查看发布页面”的问题：限流回退现在会从发布包中读取 `SHA256SUMS.txt`，为 DMG / ZIP / PKG 建立可信校验，自动更新（下载 → 校验 → 替换 → 重启）在限流场景下也可正常完成。

### 安装

下载 `Scriptser-1.2.4-universal.dmg`，打开后将 `Scriptser.app` 拖入“应用程序”。打开应用后点击菜单栏的终端图标，进入“管理”。现有脚本和偏好设置会保留。

此构建沿用此前版本的 ad-hoc 签名，未经过 Apple Developer ID 签名或公证。如果 macOS 阻止首次打开，请确认下载来源，并按系统提示在“系统设置 → 隐私与安全性”中选择“仍要打开”。

`SHA256SUMS.txt` 提供安装包校验值。
