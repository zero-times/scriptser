Scriptser 1.1.0 适用于 macOS 13+，本安装包同时支持 Apple 芯片（arm64）和 Intel（x86_64）。

### 新功能

- **AI Skill**：在管理窗口选择并记忆 Skill 目录，一键生成覆盖应用全部界面操作的 Skill。提供预览、打开文件夹和复制添加指引；正式版与 DEV 的 Skill 可并存。
- **进程详情**：管理列表、菜单栏和输出窗口显示运行脚本的 PID，包括应用重启后恢复的进程。
- **结束进程**：确认脚本名和 PID 后强制结束指定进程，拒绝使用过期 PID 的确认。原有“停止”继续发送正常终止信号。
- **应用图标**：新增 macOS 应用图标。

### 修复

- 统一管理窗口入口，避免重复打开管理窗口。
- 改进更新检查的并发请求、缓存及 GitHub 限流处理。
- 改进添加自定义命令入口。

### 安装

下载 `Scriptser-1.1.0-universal.dmg`，打开后将 `Scriptser.app` 拖入“应用程序”。更新前先退出旧版本。打开应用后点击菜单栏的终端图标，进入“管理”。现有脚本和偏好设置会保留。

此构建沿用 v1.0.0 的 ad-hoc 签名，未经过 Apple Developer ID 签名或公证。如果 macOS 阻止首次打开，请确认下载来源，并按系统提示在“系统设置 → 隐私与安全性”中选择“仍要打开”。

`SHA256SUMS.txt` 提供安装包校验值。AI Skill 需要助手已有 macOS 界面自动化工具及辅助功能权限；“结束进程”针对单个跟踪 PID，不终止整棵进程树。

### 验证

27 项自动测试通过；Release 通用架构构建通过；包内版本、最低系统版本、中英文资源、图标、Skill 资源及代码签名完整性已核对。DEV 界面验证了 Skill 生成、更新、预览、复制指引、目录记忆、冲突错误提示，以及 PID 显示和结束确认。
