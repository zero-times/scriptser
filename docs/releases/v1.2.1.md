Scriptser 1.2.1 适用于 macOS 13+，本安装包同时支持 Apple 芯片（arm64）和 Intel（x86_64）。

### 修复

- 在菜单栏点击“管理”后，菜单栏面板会立即收起，再打开管理窗口，避免菜单栏遮挡或残留。

### 安装

下载 `Scriptser-1.2.1-universal.dmg`，打开后将 `Scriptser.app` 拖入“应用程序”。打开应用后点击菜单栏的终端图标，进入“管理”。现有脚本和偏好设置会保留。之后的新版本可以直接在应用内“安装并重启”完成更新。

此构建沿用此前版本的 ad-hoc 签名，未经过 Apple Developer ID 签名或公证。如果 macOS 阻止首次打开，请确认下载来源，并按系统提示在“系统设置 → 隐私与安全性”中选择“仍要打开”。

`SHA256SUMS.txt` 提供安装包校验值。
