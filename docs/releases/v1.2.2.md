Scriptser 1.2.2 适用于 macOS 13+，本安装包同时支持 Apple 芯片（arm64）和 Intel（x86_64）。

### 修复

- 修复自动更新“安装并重启”卡在“正在安装更新…”的问题：更新包下载完成后，应用会先收起更新窗口再退出，并由辅助进程完成应用替换与重启；即使退出被系统延迟，看门狗也会在数秒内强制退出，保证更新必定完成。重启过程中“安装并重启”按钮保持禁用，不再出现卡住后按钮可再次点击导致重复下载的情况。
- 修复下载或校验失败后更新窗口仍被禁用的问题：失败后会正确解锁界面并显示错误原因。

### 安装

下载 `Scriptser-1.2.2-universal.dmg`，打开后将 `Scriptser.app` 拖入“应用程序”。打开应用后点击菜单栏的终端图标，进入“管理”。现有脚本和偏好设置会保留。之后的新版本可以直接在应用内“安装并重启”完成更新。

此构建沿用此前版本的 ad-hoc 签名，未经过 Apple Developer ID 签名或公证。如果 macOS 阻止首次打开，请确认下载来源，并按系统提示在“系统设置 → 隐私与安全性”中选择“仍要打开”。

`SHA256SUMS.txt` 提供安装包校验值。

### 验证

30 项自动测试通过（含自动更新安装流程的回归测试）；Release 通用架构构建通过；包内版本、最低系统版本、中英文资源、图标、Skill 资源及代码签名完整性已核对。“安装并重启”卡死问题已通过最小复现程序验证：更新窗口收起后应用可正常退出并由辅助进程完成替换与重启。

English: macOS 13+ universal build for Apple Silicon and Intel. Fixed in 1.2.2: the in-app "Install and Restart" update no longer stalls on the "Installing update…" spinner. The update sheet is dismissed before the app quits, a watchdog guarantees the process exits, and the button stays disabled during restart so repeated clicks cannot trigger re-downloads. Failed downloads now unlock the UI and show the error. Mount the DMG and drag Scriptser.app into Applications. Existing scripts and preferences are retained. This release is ad-hoc signed and is not Developer ID signed or notarized.
