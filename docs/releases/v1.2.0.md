Scriptser 1.2.0 适用于 macOS 13+，本安装包同时支持 Apple 芯片（arm64）和 Intel（x86_64）。

### 新功能

- **自动更新**：检测到新版本后，在更新详情中选择“安装并重启”，应用会在线下载并实时显示进度，校验大小与 SHA-256，自动替换应用包并重启 Scriptser，不再需要手动下载、退出和覆盖安装。
- **进度与阶段提示**：更新界面显示下载百分比以及“校验 / 准备 / 安装 / 重启”各阶段状态；失败原因会在界面直接提示。
- **手动回退**：DEV 构建等无法自替换的环境保留“下载更新…”和“打开更新包”，`.pkg` 包仍走手动安装流程。

### 安装

下载 `Scriptser-1.2.0-universal.dmg`，打开后将 `Scriptser.app` 拖入“应用程序”。打开应用后点击菜单栏的终端图标，进入“管理”。现有脚本和偏好设置会保留。之后的新版本可以直接在应用内“安装并重启”完成更新。

此构建沿用此前版本的 ad-hoc 签名，未经过 Apple Developer ID 签名或公证。如果 macOS 阻止首次打开，请确认下载来源，并按系统提示在“系统设置 → 隐私与安全性”中选择“仍要打开”。

`SHA256SUMS.txt` 提供安装包校验值。
